# Supabase 스키마 적용 방법

이 폴더의 SQL은 자동으로 실행되지 않는다. **Supabase 대시보드 → SQL Editor**에
붙여넣고 Run 해야 실제 DB에 반영된다.

- `migrations/` : 기능이 추가될 때마다 쌓이는 변경분. 파일명 순서대로 실행한다.
  이미 적용한 파일을 다시 실행해도 되도록 `if not exists` 위주로 쓴다.
- `combined_schema.sql` : 새 프로젝트를 처음부터 만들 때 쓰는 전체 스키마.

## 적용이 안 됐을 때 나오는 화면

앱에서 "... 기능 설정이 아직 끝나지 않았어요"라고 뜨면 그 기능의 마이그레이션이
아직 실행되지 않은 것이다. 예를 들어 찬양콘티에서 사진은 올라가는데 유튜브 링크만
막히면 `20260827010000_praise_set_youtube.sql`을 실행하면 된다.
